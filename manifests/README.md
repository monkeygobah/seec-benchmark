# Released Manifests

These files use paper-facing names and contain one relative image path per
line.

- `pretrain/pretrain_10k.txt`: deterministic index of the local 10K subset
- `pretrain/pretrain_100k.txt`: fixed 100K pretraining subset
- `pretrain/pretrain_1m.txt`: fixed 1M pretraining subset
- `geometry/holdout.txt`: source-distribution holdout split
- `geometry/open_hr.txt`: high-resolution open-source evaluation split

Paths are expected to resolve relative to the corpus root.
